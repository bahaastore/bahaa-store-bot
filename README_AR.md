# بهاء ستور — بوت تيليجرام + تطبيق مصغّر لشحن الألعاب والتطبيقات وتحويل الرصيد

متجر كامل يعمل داخل تيليجرام، مربوط آلياً بمتجر **ماكس ستور** عبر الـ API، ويضيف **هامش ربح 30%** (قابل للتعديل) على سعر كل منتج.

---

## كيف يعمل المتجر

```
العميل ← بوت بهاء ستور ← التطبيق المصغّر (الأقسام والمنتجات بأسعارك)
        │
        ├─ يشحن رصيده (شام كاش / سيرياتيل كاش / USDT / Binance Pay)
        │      └─ يصلك إشعار في البوت ← تضغط «قبول» ← يُضاف الرصيد للعميل
        │
        └─ يشتري منتجاً ← يُخصم سعرك (سعر ماكس ستور + 30%) من رصيده
               └─ يُرسل الطلب آلياً لماكس ستور (يُخصم السعر الأصلي من رصيدك هناك)
                      ├─ نجح ← يصل الكود / الشحن للعميل فوراً عبر البوت
                      └─ فشل ← يُعاد المبلغ لرصيد العميل تلقائياً
```

الفرق بين السعرين هو **ربحك**، ويظهر لك في لوحة التحكم بالأمر `/admin`.

> **مهم:** يجب أن يكون لديك رصيد كافٍ في حسابك لدى ماكس ستور، لأن كل طلب يُنفَّذ من رصيدك هناك. إذا نفد، يُرفض الطلب ويُعاد المبلغ للعميل ويصلك تنبيه.

## ما يحتويه المتجر

| الجزء | المزايا |
|---|---|
| **التطبيق المصغّر** | 5 تبويبات (الرئيسية، طلباتي، الشحن، الإيداعات، حسابي) · أقسام متداخلة · بحث · عرض بالدولار أو الليرة · وضع نهاري وليلي · نسخ الأكواد بضغطة |
| **البوت** | رسالة ترحيب وأزرار فتح المتجر · إشعار فوري عند تنفيذ أو رفض الطلب · إشعار عند قبول الإيداع |
| **لوحة المدير (داخل البوت)** | إحصائيات المبيعات والأرباح · قبول ورفض الإيداعات بزر · تعديل الهامش وسعر الصرف · إدارة طرق الدفع · إضافة/خصم رصيد · حظر · رسالة جماعية · وضع صيانة |
| **الحماية** | التحقق من توقيع تيليجرام لكل عميل · منع تكرار رقم العملية · منع القبول المزدوج للإيداع · منع تكرار الطلب عند المزوّد (order_uuid) |

## خطوات التشغيل (مرة واحدة فقط)

### 1. أنشئ البوت
1. افتح **@BotFather** في تيليجرام ← أرسل `/newbot`
2. الاسم: `بهاء ستور` — المعرّف مثلاً: `BahaaStore_bot`
3. احفظ **التوكن** (يشبه `7123456789:AAH...`) ولا تشاركه مع أحد.

### 2. احصل على مفتاح API من ماكس ستور
افتح بوت ماكس ستور ← التطبيق المصغّر ← **حسابي ← مفاتيح API** ← أنشئ مفتاحاً وانسخه.
إذا كان المفتاح يطلب تحديد عنوان IP، أضف عنوان IP الخادم الذي ستشغّل عليه المتجر (الخطوة 4).

### 3. اعرف معرّفك الرقمي
بعد التشغيل أرسل `/id` لبوتك، أو استخدم **@userinfobot**.

### 4. شغّل المتجر على خادم يعمل 24 ساعة
المتجر يحتاج خادماً يعمل باستمرار ورابط **HTTPS** (شرط من تيليجرام للتطبيق المصغّر). الخيارات:

**الخيار أ — Railway أو Render (الأسهل، بدون أوامر):**
1. ارفع مجلد المشروع إلى مستودع GitHub خاص.
2. أنشئ مشروعاً جديداً من المستودع (يتعرّف على `Dockerfile` تلقائياً).
3. أضف المتغيرات من ملف `.env.example` في قسم Variables.
4. فعّل نطاقاً عاماً (Public Domain) وضعه في `PUBLIC_URL`.
5. أضف **Volume** على المسار `/srv/data` حتى لا تضيع قاعدة البيانات عند إعادة التشغيل.

> تجنّب الخطط المجانية التي «تُنيم» الخادم عند عدم الاستخدام، لأن البوت سيتوقف عن الرد.

**الخيار ب — خادم VPS (أفضل للتحكم وعنوان IP ثابت):**
```bash
git clone <مستودعك> bahaa_store && cd bahaa_store
cp .env.example .env && nano .env          # املأ القيم
docker build -t bahaa-store .
docker run -d --restart=always --name bahaa-store -p 8080:8080 -v $PWD/data:/srv/data --env-file .env bahaa-store
```
ثم اربط نطاقاً بشهادة HTTPS (مثلاً عبر Caddy أو Cloudflare) يوجّه إلى المنفذ 8080.

### 5. املأ ملف الإعدادات `.env`
```
BOT_TOKEN=توكن البوت
ADMIN_IDS=معرّفك الرقمي
PUBLIC_URL=https://رابط-خادمك
SUPPLIER_API_TOKEN=مفتاح ماكس ستور
MARKUP_PCT=30
SYP_RATE=13000
SUPPORT_URL=https://t.me/معرّف_الدعم
```

### 6. اضبط المتجر من البوت
أرسل لبوتك:
```
/setpay sham_cash رقم حساب شام كاش
/setpay syriatel_cash رقم سيرياتيل كاش
/setpay usdt عنوان محفظة USDT TRC20
/setpay binance_pay Binance Pay ID
/rate 13000
/admin
```
وأوقف أي طريقة لا تستخدمها بـ `/togglepay binance_pay`.

## أوامر المدير

| الأمر | الوظيفة |
|---|---|
| `/admin` | الإحصائيات: المبيعات، الأرباح، رصيدك لدى ماكس ستور |
| `/help` | قائمة كل الأوامر |
| `/markup 30` | هامش الربح العام |
| `/pmarkup 12 20` | هامش خاص لمنتج رقم 12 (و `/pmarkup 12 off` للإلغاء) |
| `/rate 13000` | سعر صرف الدولار بالليرة |
| `/pending` | الإيداعات المنتظرة |
| `/dep_ok 15` · `/dep_ok 15 9.5` | قبول إيداع (بمبلغه أو بمبلغ تحدّده بالدولار) |
| `/dep_no 15 السبب` | رفض إيداع |
| `/user 123` · `/addbal 123 5` · `/subbal 123 5` | إدارة العملاء والأرصدة |
| `/ban 123` · `/unban 123` | حظر أو إلغاء حظر |
| `/pay` · `/setpay` · `/togglepay` | إدارة طرق الدفع |
| `/notice نص` | إعلان أعلى المتجر (`/notice off` للإزالة) |
| `/maintenance on` | إيقاف الشراء مؤقتاً |
| `/broadcast نص` | رسالة لكل العملاء |
| `/refresh` | تحديث المنتجات والأسعار من ماكس ستور فوراً |

## طريقة حساب السعر
```
سعر البيع = سعر ماكس ستور × (1 + الهامش ÷ 100)   ← مقرّب للأعلى
مثال: 4.60$ × 1.30 = 5.98$   ← ربحك 1.38$
```
تُحدَّث الأسعار من ماكس ستور تلقائياً كل 10 دقائق، ويُجلب السعر الحالي لحظة الشراء، فلا تخسر عند تغيّر سعر المزوّد.

## التجربة بدون أي حسابات
```bash
pip install -r requirements.txt
DEMO_MODE=1 python main.py
```
ثم افتح `http://localhost:8080/app/` — منتجات وهمية ورصيد تجريبي 25$، ولا يُرسل أي طلب حقيقي.
(وضع التجربة يتوقف تلقائياً عند وضع مفتاح ماكس ستور الحقيقي.)
